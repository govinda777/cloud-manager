# cloud-manager

https://github.com/govinda777/hexagonal-event-driven-architecture 

Preciso que crie um prompt para criarmos um projeto usando a arquitetura desse projeto https://github.com/govinda777/hexagonal-event-driven-architecture , o projeto tem como objetivo , gerenciar criação de contas na gcp e aws , precisamos criar uma conta seed em cada provedor aws e gcp e com isso elas serem capazes de criar contas filhas que vão herdar as questões de billing da conta pai. Esse projeto terá as coisas necessárias para rodar localmente com docker e docker compose, precisamos ter uma fila e com ela gerenciar o fluxo.
